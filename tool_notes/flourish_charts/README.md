# Flourish

The embed snippet, and a screenshot of one chart. There is no template file to
download, because Flourish templates live in Flourish; what you can keep is the
embed code and the knowledge of what the tool is for.

| File | What it is |
|---|---|
| `embed_example.md` | The iframe you paste into a page to show a published Flourish chart |
| `flourish_embed_screenshot.png` | A district coverage chart, as it renders |

## When to use it

Something going out to readers. Flourish's animated bar races, scrollytelling
stories and maps are built for an audience, not for analysis, and for a
newsletter or a public-facing page they are hard to beat for the time they
take.

## When not to

The chart in the report itself, where an animation is a distraction and a
static SVG prints properly. And anything with more than a few thousand rows:
Flourish is a presentation tool, and a large dataset makes the editor slow and
the embed slower.

## What goes wrong

Published charts are public, at a URL anyone can guess from the embed, whatever
the page around them says. Do not put anything in a Flourish chart that you
would not put on the front page. And the free tier watermarks the embed; if the
chart is going into a donor deliverable, that is a conversation to have before
building it.
