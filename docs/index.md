# Welcome to InsightStack

**InsightStack** is a curated, real-world knowledge management repository created by [Varna Sri Raman](https://on-web.link/varna) — built for development practitioners, MEL professionals, researchers, and public interest technologists working on health, gender, education, and climate.

This is not a template repo. It is a live reflection of actual work — frameworks, logic models, documentation flows, and usable planning tools for India and similar contexts.

---

## 📦 What’s Inside

- ✅ Clean writing guides for briefs, memos, and field notes
- ✅ MEL frameworks, annotated logframes, indicator sets
- ✅ Fully working HTML calculators for program planning
- ✅ Tagging systems, SOPs, and file structuring protocols
- ✅ Reusable research and documentation assets

Everything is free, open, and adapted from real development program workflows.
