Welcome to InsightStack

InsightStack is a real-world documentation and knowledge repository for public interest work in India — created by Varna Sri Raman. It includes working calculators, KM standards, annotated MEL tools, and real research artefacts from health, education, climate, and gender systems.

📦 Key Folders

📝 writing_guides
Notes on writing theory of change, briefs, memos
📊 eval_docs
MEL frameworks, logframes, indicators, documentation flows
📎 annotated_research
Annotated field notes and research frameworks
🧠 learning_layers
Tools for building reflection and learning into programs
🧰 KM_tools
SOPs, tagging conventions, file structuring protocols
🧮 calculators
Working HTML tools for district/block-level planning
