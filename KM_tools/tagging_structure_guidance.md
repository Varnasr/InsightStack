# Tagging Structure Guidance

For internal drives, Notion, Baserow, or Dropbox-style KM systems, use structured tags to organize and retrieve documents faster.

---

## 🏷 Recommended Tag Axes

- **Thematic**: health, gender, education, foodculture, WEE, climate
- **Geographic**: india, assam, jharkhand, district-specific
- **Program Stage**: planning, implementation, learning, final
- **Document Type**: report, brief, deck, dataset, evaluation, toc
- **Audience**: internal, donor, govt, public

---

## 📌 Sample Tags

```
["health", "gender", "madhya_pradesh", "learning", "brief", "donor"]
["climate", "assam", "evaluation", "final", "govt"]
```

---

## 📁 Suggested Usage

- As labels in Notion databases
- In metadata columns in Excel/Baserow
- As hashtags in filenames or cloud drive folders

Create documentation SOPs that require tagging when uploading to shared folders.
