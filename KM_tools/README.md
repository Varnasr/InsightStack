# KM_tools

Conventions for organising a project's files.

| File | What it is |
| --- | --- |
| `folder_structure_template.md` | One structure, numbered in workflow order |
| `readme_template.md` | A two-page README for a project folder: people, where things are, codes, how to run the analysis |
| `file_naming_conventions.md` | `project_doctype_scope_version` |
| `tagging_structure_guidance.md` | Tag axes for a document store: theme, geography, stage, type, audience |
| `documentation_flowchart.pdf` | The path from draft to final for a brief, deck or report |

Two rules: raw data is never edited, and every table and figure in a report
comes from a script that is still in the folder.
