# 🧰 KM Tools

This folder contains real, ready-to-use knowledge management tools that support better file organization, documentation workflows, and internal communication.

---

## 📄 Included Files

- `file_naming_conventions.md` — A lightweight standard to organize files by purpose, version, and geography
- `tagging_structure_guidance.md` — A guidance note on tagging files, folders, and KM entries in systems like Dropbox, Notion, or Baserow
- `documentation_flowchart.pdf` — A sample documentation flow from draft creation to final output (brief, deck, or report)

---

These tools are especially helpful when you're setting up shared drives, internal documentation processes, or collaborative writing flows with field teams.

All tools are under MIT — adapt as needed!
