# Vensim System Models
This folder contains system dynamics models represented in Vensim's `.vmfx` format. These models explore key feedback loops in various development and public health areas.

## Models Included
1. Health System Overload
2. Labor Migration Loops
3. Agricultural Subsidy Trap
4. School Dropout Feedback Loop
5. Climate Adaptation Trap
6. Women's Livelihood Resilience Loop
7. Vaccine Hesitancy & Trust Dynamics
8. Citizen-State Welfare Feedback Loop

## How to Use
1. Download the `.txt` files in the `models/` folder and rename them to `.vmfx`.
2. Open them in Vensim or any compatible software.
3. Use the models for simulation, policy analysis, or educational purposes.

## Extensions
Feel free to modify the models. For instructions on extending and adapting these models, refer to the `how_to_extend_models.md`.

## Tools Used
This repository utilizes Vensim for system modeling. Alternative tools are listed in the `tools_used.md` file.
