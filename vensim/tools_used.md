# Tools Used in System Modeling

This section provides an overview of the tools used to develop the models in this folder, as well as free and open-source alternatives.

## Primary Tool
- **Vensim PLE**: The primary tool used for system dynamics modeling. It is a robust, professional tool for simulating feedback loops and system behaviors.

## Alternative Tools
- **InsightMaker**: Free online system dynamics modeling tool.
- **Stella Architect**: A paid, professional tool for system modeling.
- **AnyLogic**: A multi-method simulation modeling software.
- **Powersim Studio**: Another option for system modeling, supporting both discrete-event and system dynamics.
