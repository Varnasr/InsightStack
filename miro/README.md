# miro

Notes and materials for running a human-centred design session on a Miro board.

| File | What it is |
|---|---|
| `miro_use_case_india.md` | When a board is worth the setup, and when a room and paper is faster |
| `HCD_Miro.pdf` | A session structure |
| `Miro HCD Template Example.png` | What the finished board looks like |
| `Miro Purpose.png` | The framing slide |
| `sample_miro_board_links.txt` | Links to public boards worth copying from |

No board file ships here. Miro boards live in Miro and are copied from a
template rather than imported from a repository, so what is useful to keep in
version control is the session design, not the artefact.
