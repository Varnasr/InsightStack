Data starters

Loaders for real survey microdata · Stata, R, Python

28 surveys · 7 countries

DHS, South Asia

One loader for every DHS in the region, from India's NFHS-1 to NFHS-5 through Bangladesh, Nepal, Pakistan, Maldives, Afghanistan and Sri Lanka. Handles the weight scaling, the per-recode design variables and the anthropometry flags that quietly ruin a stunting rate.

Read the guide →

Fixed-width · layout-driven

PLFS, India

Reads MoSPI's unit-level text using the round's own layout rather than hardcoded byte positions, and applies the combined-estimate weight rule that is not simply MLTS/100.

Read the guide →

No data ships and none can: both DHS and MoSPI prohibit redistribution. Each folder builds synthetic fixtures instead, and the test suites run on every push.

Status

Stable

This repository works and is correct, but is not under active development. Bug reports are welcome and issues stay open; new features are unlikely, and replies are measured in weeks rather than days. Dependencies are pinned deliberately so that a clone still runs years from now. See the maintenance policy.
