Data starters

Loaders for real survey microdata · Stata, R, Python

28 surveys · 7 countries

DHS, South Asia

One loader for every DHS in the region, from India's NFHS-1 to NFHS-5 through Bangladesh, Nepal, Pakistan, Maldives, Afghanistan and Sri Lanka. Gets right the three things that quietly ruin a stunting rate: the weight scaling, the design variables, and the anthropometry flags.

Read the guide →

Fixed-width · layout-driven

PLFS, India

Opens MoSPI's unit-level files using the layout that shipped with your round, and applies the combined-estimate weight rule, which is not simply MLTS divided by 100.

Read the guide →

No data ships, and none can: DHS and MoSPI both forbid passing the files on. You download your own copy, and each guide names exactly which files to fetch.
