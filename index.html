Data starters

Loaders for real survey microdata · Stata, R, Python

28 surveys · 7 countries

DHS, South Asia

One loader for every DHS in the region, from India's NFHS-1 to NFHS-5 through Bangladesh, Nepal, Pakistan, Maldives, Afghanistan and Sri Lanka. Gets right the three things that quietly ruin a stunting rate: the weight scaling, the design variables, and the anthropometry flags.

Read the guide →

Fixed-width · layout-driven

PLFS, India

Opens MoSPI's unit-level files using the layout that shipped with your round, and applies the combined-estimate weight rule, which is not simply MLTS divided by 100.

Read the guide →

No data ships, and none can: DHS and MoSPI both forbid passing the files on. You download your own copy, and each guide names exactly which files to fetch.

Code and tooling

Technique, templates and worked examples

EconometricsPython, R Did the programme work, and can you defend the answer? Difference-in-differences, matching, instrumental variables and regression discontinuity, each with data to practise on. Stata snippets44 do-files The Stata you end up rewriting on every project: merges, labels, graphs, regressions, survey settings. SPSS scripts20 files Survey analysis for teams whose institution runs on SPSS. Network effectsPython Who influences whom in a self-help group, how far a practice spreads, and why the obvious peer-effects regression cannot answer the question it looks like it answers. ReplicationPython, R A package that checks itself: one command from raw data to results, a recorded answer, R against Python, and a test that the check can fail. Data validationPy, R, Stata, SPSS Catch what is wrong with a file, by household id, before it reaches a finding. Rules come from the data dictionary; blanks in skip-pattern questions are not flagged; sentinel codes count as missing. Label variablesPy, R, Stata, SPSS Put the labels from the dictionary into a Stata or SPSS file, where they survive. A CSV loses them on every round trip. Survey to codebookPython Turn an XLSForm into a codebook a reviewer can read top to bottom, and into the label dictionary for its own export. Reports the choice list the form names and does not have. System dynamicsVensim Where an intervention pushes back on itself: eight system models across health, agriculture, climate, migration and education. Tool notes7 tools Excalidraw, Kumu, Observable, RawGraphs, Flourish, Power BI and Miro: when each is worth the setup, when it is not, and what goes wrong, with one worked file apiece. Qualitative codingTaguette One focus group coded start to finish, and the method: decide the frame first, code two transcripts twice, count carefully. Eleven of fourteen groups is a sentence; 78 per cent of respondents is a survey result a focus group cannot give. Recorded fieldworkDescript From recording to clip to quote, and what is decided at each step. Three separate consents, every quote checked against the audio, and a clip cut with its context visible to whoever approves it. Annotated research5 briefs Five research briefs marked up with the same eight questions, weakest design to strongest. Hand one out unmarked, have readers tag it, compare. Learning libraryReference A reading shelf: programming, data science, research methods, AI tools. Learning layersPractice A MEL system that changes nothing has no learning in the calendar. Three layers at three tempos, each a decision with a date, a person and the evidence in front of them. Writing guides5 guides Theory of change, results chain, the evaluation report, the policy brief, and how to write uncertainty into the same sentence as the number. The verb is decided by the design. Evaluation documentsTemplates Logframe, indicator reference sheet and MEL framework: the template, how to fill it in outcome-first, and the errors that recur. The assumptions column is the programme's theory. Knowledge managementConventions One folder structure and a README template, so a file's location says what it is. Raw data is never edited; every table came from a script still in the folder.

These open on GitHub, where the code lives.
