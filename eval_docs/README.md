# eval_docs

Templates for the logframe, the indicator reference sheet and the MEL
framework, with a completed example of each.

| File | What it is |
| --- | --- |
| `logframe_template.md` | The four-row table, how to fill it in outcome first, and common errors |
| `logframe_template.csv` | The same table as a spreadsheet |
| `logframe_mhh_program.xlsx` | A completed example: school health clubs for menstrual health |
| `indicator_reference_sheet.md` | One sheet per indicator |
| `indicator_reference_sheet.csv` | The fields as columns, for a whole indicator set |
| `indicator_guidance.md` | Five tests for an indicator, the types, and common errors |
| `mel_framework_outline.md` | Nine sections, with the question a reviewer asks of each |
| `mel_framework_mhh_program.pdf` | A completed example, same programme |

The completed examples describe a hypothetical programme.

The assumptions column of the logframe, between outputs and outcomes, states
the programme's theory in one sentence. If it cannot be written, there is no
theory yet.

Related: `../writing_guides/` for the theory of change note and results
chain; `../annotated_research/` for what each evaluation design can claim;
FieldStack `survey_tools/` for sample size and `field_ops/` for data quality
checks.
