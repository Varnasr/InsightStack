# Taguette Coding

This folder contains a real field-based qualitative transcript coded using [Taguette](https://taguette.org), an open-source tool for visual tagging.

## 📂 Folder Contents
- `chhattisgarh_chw_fgd.txt` – Real translated field transcript from a community health worker
- `chhattisgarh_chw_fgd.tag.json` – Taguette-compatible tag file with three theme codes
- `tag_summary_export.html` – Visual export of tags with sample quotations

## 🧠 Use Case
Taguette supports thematic coding of qualitative transcripts like FGDs and interviews. This example is from a CHW in rural Chhattisgarh describing climate-driven fieldwork adaptations. Useful for researchers, MEL teams, and documentation practitioners.
