# Kumu Stakeholder Map

This folder contains a JSON-format stakeholder map and a preview visual representing key actors in a district public health delivery network.

## 📂 Folder Contents
- `district_health_network.json` – Simplified map structure in Kumu-compatible JSON format
- `district_health_network.png` – Visual rendering of map for documentation or sharing

## 🧠 Use Case
Kumu helps visualize complex systems such as community health, education delivery, or program stakeholder networks. This example shows how a district health MEL team can map supervisory and service-delivery relationships between PHCs, CHWs, and pregnant women.
