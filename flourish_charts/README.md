# Flourish Chart Embeds

This folder contains example embeds and visuals based on [Flourish](https://flourish.studio), a popular tool for visual storytelling and interactive dashboards.

## 📂 Folder Contents
- `embed_example.md` – HTML iframe code to embed a Flourish chart
- `flourish_embed_screenshot.png` – Screenshot of a district chart with coverage indicators

## 🧠 Use Case
Flourish helps NGOs, MEL teams, and policy advocates share data interactively — without needing coding skills. It's widely used in India for disaggregated visual storytelling, report supplements, and digital dashboards.
