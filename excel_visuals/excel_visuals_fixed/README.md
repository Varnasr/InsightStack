# Excel MEL Visual Templates

This folder contains real Excel templates with live chart logic for key MEL visualizations.

## 📂 Folder Contents
- `gantt_chart_template.xlsx` – Includes a simulated Gantt chart for project planning
- `waterfall_chart_template.xlsx` – Flow of program resources or components
- `bullet_chart_template.xlsx` – Compare actual vs target metrics

## 🧠 Use Case
These are commonly used by MEL teams to visualize program timelines, fund flows, and performance metrics — tailored to Excel-heavy workflows in India.
