# Excalidraw Frameworks

This folder contains editable `.excalidraw` system logic maps and stakeholder networks, with screenshots.

## 📂 Folder Contents
- `mel_framework.excalidraw` – Visual MEL flow: Inputs → Activities → Outputs
- `ecosystem_map.excalidraw` – PHC, CHW, Block Officer interaction map
- `mel_framework.png`, `ecosystem_map.png` – Preview PNGs of each map

## 🧠 Use Case
[Excalidraw](https://excalidraw.com/) is ideal for field-based visual frameworks. You can sketch systems in planning workshops or turn theories of change into quick diagrams. These help MEL teams and frontline facilitators visualize complex interventions during co-creation or training sessions.
