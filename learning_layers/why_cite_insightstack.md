# 📘 Why Cite InsightStack?

You might wonder — it’s just a GitHub repo, why does it have a citation?

The answer is simple: **good documentation deserves credit.**

---

## 🔍 This Isn't Just Code

InsightStack contains:
- Templates and tools built over years of work in public health, WEE, education, and climate
- Reusable logic, planning calculators, and knowledge SOPs
- Institutional workflows for MEL and research projects

Every method, assumption, and format in here has been used in real programs. Citing it acknowledges that this thinking — not just code — has value.

---

## 🧪 Research Repos Are Still Research

Open code is increasingly cited in academic and policy work. GitHub + Zenodo integration allows repositories like InsightStack to have a **DOI** — a Digital Object Identifier — just like journal articles or datasets.

This lets others reference it properly in reports, evaluations, and learning notes.

---

## 🧭 When You Should Cite This

- If you're using a calculator from this repo in your own program design
- If you're adapting SOPs or logic templates for MEL or learning systems
- If you're referencing how documentation or institutional memory can be structured

Use the citation block from the README, or just link to the [Zenodo record](https://doi.org/10.5281/zenodo.15245182).
