# learning_layers

Learning from a programme's own data, treated as scheduled decisions.

| File | What it is |
| --- | --- |
| `embedding_learning_in_the_mel_cycle.md` | Three layers at three tempos, each a decision with a date, a person and the evidence in front of them |
| `learning_layer_framework.pdf` | The framework the note draws on, written for health systems |
| `why_cite_insightstack.md` | Why a repository of methods and templates carries a DOI |

Start from the decisions the programme will take in the next year, write
down who takes each, when, and what evidence could change it, and design the
data collection from that. Monitoring data cannot answer an annual decision
and an evaluation cannot inform a monthly one.

Related: `../eval_docs/mel_framework_outline.md`, section 7.
