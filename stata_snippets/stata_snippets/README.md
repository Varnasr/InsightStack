# Stata MEL Scripts

This folder contains `.do` scripts for standard analysis in Monitoring, Evaluation, and Learning work using [Stata](https://www.stata.com/).

## 📂 Folder Contents
- `survey_weights.do` – Survey design and weighting syntax for Indian household surveys
- `did_estimator.do` – Difference-in-Differences model for before-after evaluation
- `equity_plot.do` – Code to visualize coverage by economic quintile
- `sample_mel_data.csv` – Sample MEL dataset to test the code

## 🧠 Use Case
These scripts are used in evaluations of public programs, social protection, and gender audits. They follow common practices in Indian survey data analysis and program evaluation.
