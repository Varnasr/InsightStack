# 🗂️ Repo Hygiene Checklist

- [ ] LICENSE.md present (MIT)
- [ ] README.md complete (badges, overview, folders)
- [ ] GitHub Pages active (if applicable)
- [ ] CONTRIBUTING.md present
- [ ] CODE_OF_CONDUCT.md present
- [ ] CITATION.cff present
- [ ] FUNDING.yml present
- [ ] Donation link added in README
- [ ] Auto-updating CHANGELOG.md working
- [ ] Zenodo DOI registered and badge added
- [ ] Roadmap or planned features documented
- [ ] All folders contain real, non-placeholder content
