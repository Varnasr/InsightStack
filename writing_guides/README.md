# writing_guides

Guides for the documents an evaluation produces, in the order they are
written.

| Guide | What it is for |
| --- | --- |
| `theory_of_change_notes.md` | The programme's theory as a short note: problem, pathway, assumptions, outcomes. `sample_theory_of_change_note.pdf` is a worked example; the `.qmd` is its Quarto source |
| `results_chain.md` | The theory one link at a time: "if A then B because C" |
| `evaluation_report_structure.md` | What goes in which section, and which verb each design permits in the summary |
| `policy_brief.md` | Two pages, one message, one ask |
| `writing_about_uncertainty.md` | Sampling, design and measurement uncertainty, written in the same sentence as the number |

The design decides the verb. "Rose among participants", "was higher than in
comparison areas", "increased relative to comparison areas" and "caused" are
claims of different strength, and the methods section fixes which one the
summary may use. `../annotated_research/` has five reports read this way.
