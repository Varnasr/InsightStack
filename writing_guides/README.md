# writing_guides

Notes and a template for writing a theory of change.

| File | What it is |
|---|---|
| `theory_of_change_notes.md` | The notes: what a theory of change is for, where they go wrong, what a reader should be able to check |
| `theory_of_change_notes.qmd` | The same as a Quarto source, if you want to render it or adapt it |
| `sample_theory_of_change_note.pdf` | A worked example, rendered |

The writing-up is usually the part that decides whether an evaluation is used,
and it is the part least often planned for. A theory of change written after the
results are in tends to be a description of what happened rather than a claim
anyone could have disagreed with beforehand, which is the whole point of having
one.
