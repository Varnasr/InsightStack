# Observable Notebooks

Interactive, real-time data storytelling with embedded charts and logic flows. Built using [Observable](https://observablehq.com/), these notebooks help visualize district health vulnerabilities and MEL results.

## 📂 Folder Contents
- `district_vulnerability_dashboard.ojs` – A notebook that visualizes vaccine coverage and availability across districts
- `public_health_data.csv` – Dataset with coverage and population data
- `dashboard_screenshot.png` – Screenshot of the dashboard view

## 🧠 Use Case
Observable is powerful for creating real-time dashboards and exploring spatial or temporal field data. Useful in MEL teams, participatory planning, or district dashboards in India.
