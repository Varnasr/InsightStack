# 📚 Learning Materials: Development Economics & Research

## 📘 Overview
This folder curates foundational and creative learning material across research methods, development economics, applied data science, and experimental design. It combines visual aids, methodological handbooks, authored short courses, and essential readings to support learners and educators alike.

## 📂 Contents Summary
1. `Research Methods Handbook.pdf` – A practical primer on qualitative and mixed-methods approaches, ideal for early-career researchers.
2. `101 Data Science Drawings.pdf` – Visual explainers for key concepts in statistics, ML, and applied econometrics; includes sketch-style charts.
3. `Learning Generative AI Tools for Excel.pdf` – A quick-start visual guide to using GPT-style assistants within Excel workflows.
4. `Network Collective Action.pdf` – A conceptual and graphical walkthrough of how social networks affect coordination and mobilization.
5. `DevEcon 101.pdf` – Authored short course in Development Economics by Dr. Varna Sri Raman, combining visual learning, South Asia–focused examples, and applied exercises.
6. `DevEcon 101.deck` – Editable design file for the course, usable in Figma or other deck-building tools.
7. `Principles_of_Development_Economics.pdf` – Comprehensive reference textbook, covering theory, tools, and applied themes in dev econ.
8. `Quant Methods for the Social Sciences.pdf` – A structured book introducing SPSS/Stata-based social science analysis with real-world survey examples.
