# Learning Library

Welcome to your enriched learning library — a curated collection of books, handbooks, and visual materials across programming, data science, research methods, and AI-powered tools.

Each folder below contains:
- 📘 Fully referenced PDFs
- ✍️ Human-written summaries
- ✂️ Key excerpts
- 🔖 Tags for discoverability
- 🧰 Practical templates or prompts (where applicable)

## 🧭 Suggested Learning Paths

- 🎨 **Creative Coders** → Start with `01_programming/`, then check visuals in `05_visual_summaries/`
- 📊 **Aspiring Analysts** → Begin with R in `02_data_science/` and reinforce using visual guides
- 🎓 **Researchers & PhD students** → Start with `03_research_methods/`, then apply methods using R or Excel
- 🤖 **AI Tinkerers** → Explore Excel+ChatGPT in `02_data_science/` and future prompts in `04_ai_tools/`
