# 📚 InsightStack – Learning Library

Welcome to the InsightStack Learning Library — a curated, structured, and enriched folder of books, handbooks, visual references, and templates across key knowledge domains:

- 🎨 Programming & Creative Coding
- 📊 Data Science with R and Excel
- 🎓 Research Design & Methodology
- 🤖 AI-enhanced Workflows
- ✍️ Visual Learning & Concept Sketches

Each folder includes:
- PDFs or guides
- README with summary, tags, and key excerpts
- Cross-references to related folders
- Prompts, cheatsheets, or learning templates where applicable
