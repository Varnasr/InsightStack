# Visual Ethnography with Descript

This folder demonstrates how to layer field-based transcripts into narrated visual ethnographies using [Descript](https://www.descript.com/), a multimedia editing tool.

## 📂 Folder Contents
- `climate_field_transcript.txt` – A real narrative transcript from field interviews on climate change
- `descript_storyboard.md` – Step-by-step narration cues and visual prompts for producing an ethnographic video

## 🧠 Use Case
Descript is excellent for turning raw transcripts into multimedia storytelling. This example supports research teams and MEL practitioners in communicating lived realities through narrative voice and field visuals — especially for participatory documentation in India.
