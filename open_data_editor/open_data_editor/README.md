# Open Data Editor Tools

This folder includes real visual outputs and dataset examples from RawGraphs, Datawrapper, and the Open Data Editor.

## 📂 Folder Contents
- `district_health_gaps.csv` – Multivariate development indicators for Indian districts
- `stacked_bar_chart.png` – Exported bar chart visual created using pandas/matplotlib, compatible with RawGraphs formats

## 🧠 Use Case
Tools like RawGraphs and Datawrapper enable field teams and MEL specialists to create fast, explainable visualizations from survey and administrative data. This supports storytelling, advocacy, and participatory planning in development programs across India.
